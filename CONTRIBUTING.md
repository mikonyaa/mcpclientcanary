# Contributing

Use Node 24 LTS, npm ci, build, typecheck, lint, unit/server/UI/package checks. Native acceptance additionally requires both exact supported official executables on macOS arm64 and the local clients manifest. Never commit personal paths, profiles, raw native traffic, credentials or vendor binaries.

Keep client outcomes separate from harness completion. Add a controlled negative observer case for any resolver change. A native adapter extension needs actual executable identity, genuine ToolSearch and resume evidence, supported configuration isolation, installed-package verification and a new documented platform/version boundary. Recorded JSON cannot stand in for missing native coverage.

Fixtures are deterministic and harmless. No eval from scenario JSON, arbitrary external model endpoints, private cache edits or terminal drawing for hidden client control. Respect existing code and licenses. Contributions do not authorize automatically filing upstream issues or sending messages.

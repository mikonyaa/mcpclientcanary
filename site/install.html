Install and run your own measurement.

MCPClientCanary 0.1.0 measures the real Claude Code CLI with a synthetic stdio fixture and local Messages/SSE endpoint. Native support is verified for macOS arm64 and Claude Code 2.1.294 / 2.1.296. Use Node.js 22.16+ or 24 LTS.

Download release assets and checksums · Source and full instructions · Play the actual terminal recording

1. Install the verified release package

mkdir canary-consumer
cd canary-consumer
npm init -y
gh release download v0.1.0 --repo mikonyaa/mcpclientcanary --pattern '*.tgz'
npm install --ignore-scripts ./mcpclientcanary-0.1.0.tgz
./node_modules/.bin/mcpclientcanary --version

The package includes compiled code, its own fixture server, schemas and examples. Vendor executables are acquired separately; they are governed by Anthropic's terms.

2. Explicitly acquire the two official versions

node node_modules/mcpclientcanary/examples/acquire-clients.mjs \
  --cache ./canary-native-cache --manifest ./clients.local.json
./node_modules/.bin/mcpclientcanary doctor --clients ./clients.local.json --json

The helper checks the official manifest and pinned SHA-256 values. It requires a new cache, never runs the vendor installer and never changes your current installation or account.

3. Run the native lifecycle

./node_modules/.bin/mcpclientcanary run --clients ./clients.local.json \
  --suite core --repeat 2 --out ./core-results

Open core-results/report.html locally. The JSON and JUnit outputs retain separate server, loaded reference, current model input and native resume evidence. Exit 1 means a measured client contract violation; it does not mean the harness failed.
